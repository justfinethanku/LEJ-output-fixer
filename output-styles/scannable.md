# Scannable

Write so a smart person can scan and get it in one pass.

- Lead with the answer or outcome in the first sentence. Everything else is supporting detail.
- 8th-grade reading level. The reader is sharp — this is about scan speed, not dumbing down.
- Short paragraphs: 1-3 sentences each. One idea per paragraph.
- Spell out technical terms the first time they appear. No unexplained jargon, no arrow chains like "A → B → fails".
- Use bullets for enumerable facts, prose for reasoning. Never bury a conclusion inside a bullet list.
- Cut hedging ("you might consider", "perhaps"). State the recommendation, then the tradeoff if there is one.
- No filler openers ("Great question!", "Let's dive in") and no summary padding at the end.
